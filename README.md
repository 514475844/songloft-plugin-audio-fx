# 音效工坊（audio-fx）

Songloft 插件：给正在播放的歌加**混响**、**立体声展宽**和**均衡器**。

音效不在插件里自己实现，而是调用宿主播放器的官方音效接口（`player.audioEffects`），由客户端统一处理——安卓和网页端表现一致，不抢占播放器，不与宿主 EQ 打架。

## 功能

- **混响**：房间（room）/ 音乐厅（hall）
- **立体声展宽**：轻微（subtle）/ 宽阔（wide）
- **均衡器**：跟随宿主返回的预设列表动态展示
- 三种音效可叠加，一次点击即生效；再次点击取消
- 偏好自动记忆（本地 + 服务端各存一份）
- 自动跟随播放：宿主播放新会话时自动补取音效会话

## 使用

1. 安装插件后打开「音效工坊」页面
2. 选择一个歌单，点「播放此歌单」——**音效只作用于由本插件发起的播放会话**（宿主安全设计，防止后台插件偷改用户音效）
3. 播放开始后点选想要的混响 / 展宽 / EQ 预设即可

## 平台支持

| 平台 | 状态 |
|---|---|
| Android（Lynx 客户端 dev 构建起） | ✅ |
| Web（主程序内嵌页） | ✅ |
| iOS / macOS / Windows | 宿主已接入，待真机验收 |
| DLNA / 米家音箱投屏 | ❌ 投屏输出不经过宿主音效链 |

需要服务端 ≥ v2.13.13 且客户端为支持音效 SDK 的版本；旧客户端打开插件会提示不支持。

## 说明

- 混响/展宽生效时宿主会自动留出增益余量，输出音量可能略降，属预期行为。
- 关闭插件页面不影响已应用的音效；宿主另行播放、停止或手动调宿主 EQ 时会话自动失效。
